# 🤖 AI Chatbot FAQ Automation

An AI-powered FAQ chatbot that automatically understands user questions and provides relevant answers from a predefined FAQ knowledge base. The project is designed to reduce repetitive support tasks and provide quick, consistent responses through a simple web interface.

## 🚀 Features

* 💬 Interactive chatbot interface
* 🤖 AI-powered question understanding
* 📚 FAQ-based automated responses
* ⚡ Fast and simple response system
* 🌐 Web-based user interface
* 🔄 Automated FAQ handling
* 📱 Simple and responsive UI
* 🧩 Modular Python backend
* 🔧 Easy to customize with new FAQs

## ⚙️ How It Works

```text
User Question
      ↓
Chatbot Interface
      ↓
Question Processing
      ↓
FAQ / Knowledge Base
      ↓
Relevant Answer
      ↓
Response Displayed to User
```

The user enters a question through the chatbot interface. The backend processes the question and identifies the most relevant FAQ information before returning an automated response.

## 💻 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/niyaz1706/ai-chatbot-faq-automation.git
```

### 2. Navigate to the Project

```bash
cd ai-chatbot-faq-automation
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

**Windows:**

```bash
venv\Scripts\activate
```

**Linux / macOS:**

```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
python app.py
```

### 7. Open in Browser

Open:

```text
http://127.0.0.1:5000/
```
